# 共好｜社區診所集中支援管理中心

繁體中文、無執行時外部依賴的靜態互動模擬器，聚焦中心營運規劃。

## 使用

以 HTTP 伺服器提供 `dist` 目錄，例如 `python3 -m http.server 4173 --directory dist`。
不需建置。Sites 以 `.openai/hosting.json` 指定靜態目錄與專案。

- 調整 1–200 家診所、採購、IT、共用行政、標準化、流程差異、行政現金實現比例與例外申請。
- 即時比較每家成本、中心全成本回收月費、中心預算、試算收費收支、工時、流程彈性及協調投入。
- 提供三種情境、重設、保留一個比較情境、CSV 匯出（假設、結果與完整 1–200 家敏感度）。
- 目前與比較情境僅存在訪客瀏覽器 localStorage；不蒐集、上傳或跨裝置同步。
- 多方治理提案中，私人保險為六方之一，無單一方過半；席次不參與成本公式。

## 模型

所有數字、函數與係數均為教育性示範假設，不是台灣實證、報價或現行制度。模型在頁面列出全部公式與可編輯基準。以相同診療量、平均同規模診所、等額分攤比較。

每家集中後成本 = 單獨經營成本 − 診所端採購／IT／行政現金節省 + 中心全成本 ÷ 診所數。
中心全成本 = 固定配置 + 變動服務 + 一次性建置導入費 ÷ 攤提月數。
試算月費只改變中心收入，不改變上式的資源成本。全體成本不重複加計中心支出。
工時釋出與現金節省分開；計算全體淨省工時時，扣除中心投入工時。

預設 60 家情境：中心月預算 979,490 元；每家所需月費約 16,325 元；每家月淨省約 10,504 元；轉正門檻 33 家。以上皆是示範輸出。

## 驗證

`npm test` 使用 Node 內建測試器：手算核對、972 組配置的成本恆等式與邊界、行政現金實現、收費隔離、例外取捨、轉正門檻與輸入正規化。

`tests/browser.cjs` 使用 Playwright 與 Chromium，已驗證鍵盤與滑桿、數字輸入邊界、即時重算、例外切換、收費隔離、全部預設情境、保存與重設、CSV 下載及 1440／768／375 px 無橫向溢出。測試依賴可獨立安裝 `playwright` 與 `@sparticuz/chromium`；以 `CHROMIUM_EXECUTABLE` 指定已安裝的 Chromium。瀏覽器測試會自動啟動本地靜態伺服器。

## 隱私與部署

使用 Sites 私密部署；未要求擴大對象時，維持僅擁有者可存取。頁面 robots 指令不等同存取控制，實際權限由 Sites 控制。
